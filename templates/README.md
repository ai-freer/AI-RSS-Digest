# AI-RSS-Digest 提示词

执行流程以 [SKILL.md](../SKILL.md) 为准，数据合同见 [模板指南](../reference/GUIDE-templates.md)。

- `prompt-editorial.md`：全候选评审、证据、类型化评分和事件归组。
- `prompt-deep-read.md`：入选 Tier1 逐篇精读。
- `prompt-summarize-tiered.md`：按已选名单汇总 Tier2。
- `prompt-retrospective.md`：每七期复盘，结合人工标注校准。
- daily/quick/tech-dev/product/executive：保留的阅读风格参考；所有模式均先评审并完成精读，不作为独立选稿入口。

修改评审规则需更新 policy.version、重新 prepare，保留旧评审快照。提示词中的分数门槛不代表已获人工金标验证。
